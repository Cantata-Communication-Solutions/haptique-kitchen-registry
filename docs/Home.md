# Haptique Kitchen Developer Docs

Haptique Kitchen is the community extension registry for Haptique OS.

The Beta model is local-first:

1. Users browse and install from inside Haptique OS.
2. The registry is public and GitHub-backed.
3. AI Driver Builder can create a local driver package.
4. Public listing requires registry validation and Haptique review.
5. High-quality community packages can graduate into future core OTA releases.
