# Trust Levels And OTA Graduation

Haptique Kitchen is also a graduation pipeline for future OTA features.

```text
Local Dev -> Submitted -> Community -> Verified -> Core Candidate -> Core OTA
```

## Community

Passed automated registry validation and maintainer review.

## Verified

Passed stronger install, uninstall, runtime, diagnostics, compatibility, and UI review.

## Core Candidate

Accepted by Haptique as a candidate for future OS inclusion.

## Core OTA

Maintained by Haptique and shipped as part of Haptique OS.

## Deprecated

No longer recommended.

## Blocked

Blocked due to security, safety, legal, or compatibility risk.
