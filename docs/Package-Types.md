# Package Types

Haptique Kitchen supports five package types.

## Driver

Adds support for a device, protocol, API, bridge, or local service.

Drivers must declare capabilities, commands, state, permissions, config schema, diagnostics, and Logical Device UI hints.

## Widget

Adds an optional dashboard or control surface. Widgets are reviewed separately from core Logical Device UI and must be removable without removing the device.

## Recipe

Adds automation triggers, conditions, and actions that the user can inspect before enabling.

## Scene

Adds reusable scenes or experience packs for rooms and device groups.

## Builder Template

Adds AI Driver Builder starter context, validation profiles, examples, or generation templates.
